🐍 Python SDK (claw_adapter.py)

The standard integration for Python-based Agentic frameworks like LangChain, OpenClaw, and AutoGPT. It uses the ctypes library to bind directly to the native DLL.

import ctypes
from adapters.claw_adapter import VajraClawAdapter

# Initialize the C-FFI wrapper and point it to your physical matrix
claw = VajraClawAdapter("./vajraclaw_sdk/vajra_claw.dll", "Vajra.md")

# Bind to the LLM Stream

for chunk in llm.stream(clean_prompt):
    # Physical check on every token

📦 Node.js / TypeScript SDK (claw_adapter.js)

Designed for VSCode Extension developers (like Continue.dev forks) and JavaScript-based agents. We use ffi-napi to load the C library natively into the V8 engine.

const { VajraClawAdapter } = require('./vajraclaw_sdk/nodejs/claw_adapter');

// Initialize the FFI-NAPI wrapper
const claw = new VajraClawAdapter("./vajraclaw_sdk/vajra_claw.dll", "Vajra.md");

// Async generator for LLM stream interception
async function processStream(llmStream) {
    for await (const token of llmStream) {
        if (!claw.streamMonitor(token)) {
            throw new Error("PHYSICAL FUSE BLOWN");
        }
        process.stdout.write(token);
    }
}
